# Dr. Sina Dehghan — resume website

Bilingual (Persian / English) one-page resume site, served with GitHub Pages.

- `index.html` — the built page (do not edit by hand)
- `assets/` — images, video, certificates and resume PDFs
- `beta/` — the two demo panels (pharmacy shortage log, emotional intelligence)
- `src/index.tpl.html` — page source; run `python3 src/build.py` to rebuild `index.html`
